Palette Thumbnail Builder

Build the Level Editor’s compact resources/palette/thumbnails.png and thumbnails.json directly in the browser. This page reuses the game’s JavaScript character runtime, so enemy colour replacements and assembled poses match the real renderer.

If the browser supports the File System Access API, the builder can write directly into resources/palette. Otherwise use the generated download links below and copy the files manually.

  • The page keeps the same thumbnail JSON format used by the Level Editor.
  • Enemy thumbnails are assembled with the runtime character system, not by crude atlas cut-outs.
  • The builder defaults to 64 px thumbnails but keeps 128 px ready as a one-click rebuild.
