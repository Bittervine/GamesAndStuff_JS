Select a complete folder or a portable group of files. Puppet Forge resolves the references inside the character, rig, atlas, and animation JSON in memory; browsers never grant silent folder access.

Atlas parts

At 100% zoom, one atlas image pixel equals one preview-canvas pixel. Drag empty image space to draw a frame, drag inside a frame to move it, and drag a selected corner to resize it. Shift-drag or middle-drag pans the atlas.

Animation preview

Animation track

For X, Y and Angle mode, drag inside the selected yellow rectangle to move the part and drag a yellow corner handle to rotate it. The first drag creates transform keys at the playhead. For single properties, edit the numeric value directly; typing at an unkeyed playhead creates a key automatically.

Base rig / setup values

Draw order runs from back to front. The first part is drawn lowest; the last part is drawn on top.

Pivot and target height define shared sprite geometry. Setup offsets and base scale are still used by the current procedural airborne poses and as rig defaults, but a data-driven clip such as Run supplies its own absolute X, Y, and scale values while that clip is playing.
