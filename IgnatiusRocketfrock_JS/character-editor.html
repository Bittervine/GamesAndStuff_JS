Metadata

Atlas parts

At 100% zoom, one atlas image pixel equals one preview-canvas pixel. Drag empty image space to draw a frame, drag inside a frame to move it, and drag a selected corner to resize it. Shift-drag, middle-drag, or right-drag pans the atlas.

Animation

The editor owns the alpha tracks for these frame parts. Selecting a frame creates exclusive step keys for every frame at the playhead.

With alpha preview on, parts use their in-game opacity. With it off, the selected part is fully opaque while other parts are ghosted between 10% and 50%, making rear and hidden parts easier to position and select.

Duplicate current creates a new in-memory animation file and adds its slot to the character definition. Download both changed JSON files to keep the new clip.

Keyframe

For X, Y and Angle mode, drag inside the selected yellow rectangle to move the part and drag a yellow corner handle to rotate it. When a parent pivot constraint is active, dragging inside the part moves its cyan parent point instead; X/Y tracks are read-only and regenerated automatically. Drag a diamond in the bottom timeline to move its editable key time. For single properties, edit the numeric value directly; typing at an unkeyed playhead creates a key automatically.

Rigging

Color Exchange

Threshold 0.0 changes only an exact channel match. Threshold 1.0 accepts the complete channel range. Alpha is preserved, and the recolored sprite is generated once and cached.

Parent pivot constraint

The selected part's existing pivot is pinned to this normalized point on its parent. X/Y animation tracks are generated automatically; rotation and scale remain independent.

Projectile handoff

The projectile remains animation-controlled before Release time. At that time the game copies its sampled world position, hides the rig part, and gives the projectile to the simulation. The final keyed time is shown only as a reference. Pathing modes are reserved for a later obstacle-planning pass.

Draw order runs from back to front. The first part is drawn lowest; the last part is drawn on top.

Pivot and target height define shared sprite geometry. Setup offsets and base scale are still used by the current procedural airborne poses and as rig defaults, but a data-driven clip such as Run supplies its own absolute X, Y, and scale values while that clip is playing.
