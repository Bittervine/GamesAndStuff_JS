Wizard Rocket Runner Rig

This rig only uses the provided pieces: robe, head, hat, left arm, right arm, left leg sprite, right leg sprite, and rocket. The renderer always draws left arm, left leg, rocket, right leg, robe, head, hat, then right arm.

Selected part tuning. Pivot values are normalized across each trimmed sprite: 0,0 is top-left and 1,1 is bottom-right.

Rig JSON. Edit it here, apply it, copy it, or download it as wizard_rig_config.json. The draw order is deliberately locked by the renderer even if this JSON is edited.

File overrides. Use these while tuning, or place PNGs next to this HTML file using names such as wizard_robe.png and wizard_left_arm.png.
