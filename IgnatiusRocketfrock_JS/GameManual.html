Ignatius Rocketfrock Manual

Quick reference for starting, moving, fighting, and using the in-game menu.

Start

The game opens on the title card. Press a key, click, tap, or use the Start button to begin. That first interaction also unlocks the browser audio system.

The Manual link is available from the title card before the game starts.

Goal

Guide Ignatius through the cave, survive hostile creatures and hazards, operate useful devices, and reach the exit door.

Rocketfrock

  • The rocket pack can boost, slow falls, and fire homing rockets.
  • Fuel only recharges after Ignatius returns to the ground.
  • Homing rockets prefer active targets in the direction Ignatius is facing.

Power-ups

  • Collected power-ups disappear and return after 60 seconds, so it can be worthwhile to revisit an earlier part of a level.
  • The top-left Power bar shows the highest-priority active effect and its remaining duration. Speed Shot is shown ahead of wrench effects, but both remain active at the same time.
  • Speed Shot lasts 8 seconds. It doubles the rocket firing rate and halves the fuel cost of each launch.
  • Wrench power-ups last 15 seconds and replace any other active wrench. A random wrench pickup chooses its type when the level starts and rolls a new type whenever it respawns.
  • Rockets modified by a wrench carry a fuzzy outline in that wrench's colour, so the current payload remains visible even after launch.

Bigbomb (red)Fires one large, slow-turning rocket at half speed. It costs three times the fuel, deals triple damage, and damages an area about three wizard heights wide.
Boomerang (magenta)Fires a normal homing rocket. If no target remains, or after it destroys its target, it homes back toward Ignatius. Catching it refunds half the launch fuel, but hitting an enemy or obstacle on the return trip makes it explode with no refund.

Health

  • Damage briefly grants invulnerability, shown by the health meter feedback.
  • Health regenerates after a delay if Ignatius avoids further damage.
  • Some hazards are damaging; explicitly lethal hazards may defeat Ignatius immediately.

Menu

  • Settings adjusts effects volume, music volume, difficulty, rendering quality, and browser fullscreen policy.
  • Restart level restarts the current level and resumes play.
  • Exit to Title appears while the game is running and returns to the title card.
  • Exit to desktop appears only in the Electron build.

Settings

  • Effects volume controls sound effects.
  • Music volume controls the synthesized level music.
  • Difficulty currently changes only incoming damage to Ignatius.
  • Rendering quality changes visual particle density without changing gameplay timing or collision.
