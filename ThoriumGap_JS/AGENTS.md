# ThoriumGap JS Instructions

- Increment `appVersion` in `ThoriumGap.html` whenever:
  - `ThoriumGap.js` changes
  - you are about to commit and push
  - the user explicitly asks you to bump the version

- For new gameplay/UI features, consider behavior on narrow screens (narrrower than MIN_NORMAL_WINDOW_WIDTH) and how it should scale down cleanly.
